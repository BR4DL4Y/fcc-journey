## About The Project

This is a simple teacher conference scheduling form created to practice form structuring, styling, and modern CSS pseudoclasses.

### What I Learned
* How to use the `:not()` pseudoclass selector to apply clean styles efficiently without extra classes (e.g., `label:not(.contact-method)` and `input:not(.contact-method-radio-btn)`).
* How to create custom radio buttons from scratch using `appearance: none`, `::before` pseudo-elements, and CSS transitions.
* How to control smooth color transitions on `:hover` state and release.
