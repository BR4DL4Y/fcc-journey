# 🎨 Colorful Boxes (Flexbox Practice)

This repository is part of my web development learning path (`fcc-journey`). The goal of this exercise is to experiment with and understand how flex containers and flex items work in CSS.

## Learning Notes & Reflections

Flexbox properties can sometimes feel confusing and overwhelming due to the wide variety of options available (like `flex-grow`, `flex-shrink`, `flex-basis`, etc.). 

However, step by step, I am getting a solid grasp on the core concepts that make everything click:

* **`display: flex`**: The starting point to transform any layout into a flexible container.
* **`justify-content`**: Essential for controlling alignment along the main axis.
* **`align-items`**: Key for cross-axis alignment within individual lines.
* **`order`**: Super useful for rearranging elements visually without altering the HTML structure.

I know that consistent practice is the key to fully mastering it. With more projects and hands-on coding, I'll definitely master Flexbox.
