# Responsive Photo Gallery

A clean, modern, and fully responsive photo gallery built using **HTML5** and **CSS3 (Flexbox)**. This project demonstrates core layout techniques, modern box-sizing models, and responsive design principles.

# Key CSS Concepts Explored
flex-wrap: wrap: Allows gallery items to wrap onto new lines when the container width is exceeded.

justify-content: center: Centers items horizontally along the main axis.

object-fit: cover: Crops images gracefully to fill their defined bounding boxes.
