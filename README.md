## My Goal
To learn web development from scratch, practice every day, and build a solid foundation to create my own web pages.

---

## 🛠️ Projects & Practices

### 1. Coffee Shop Menu
* **Description:** A simple coffee shop page focused on basic HTML structure and introductory CSS styling. Here I learned padding, margin, font-family, font-size, `#` IDs, and `.` classes.
* **Live Demo:** [View Page](https://br4dl4y.github.io/fcc-journey/Coffee%20Shop/)

### 2. Multimedia Player
* **Description:** Practice using native HTML media tags (`<audio>`, `<video>`) and attributes.
* **Live Demo:** [View Page](https://br4dl4y.github.io/fcc-journey/Multimedia-player/)

### 3. Personal Favorite Characters Ranking 🌟
* **Description:** A top-15 character ranking page built with strict semantic HTML5, focused on web structure, accessibility (`aria-label`), and performance (`loading="lazy"`).
* **Live Demo:** [View Ranking Page](https://br4dl4y.github.io/fcc-journey/)
