# Playing Cards Project

An interactive playing cards project built from scratch using pure HTML and CSS! This exercise is part of my ongoing practice and journey in web development.

## Main Features
* **Flexbox Layout:** Clean structure to organize corner elements (`left` and `right`) and the center (`middle`) symmetrically.
* **Dynamic Rotation:** Use of `transform: rotate(180deg)` to realistically invert the bottom corners and center symbols.
* **Custom Suits:** Styled classes (`red`, `black`, `orange`) to differentiate card suits with custom borders and matching colors.
* **Hover Effect:** Subtle elevation animation on each card when hovering the cursor.
