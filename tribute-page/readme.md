# Mortal Kombat — Tribute Page

A tribute page dedicated to the history and evolution of **Mortal Kombat**, created as part of the **Responsive Web Design** certification curriculum on [freeCodeCamp](https://www.freecodecamp.org/).

## Description

This project features a responsive web page with a dark theme inspired by the classic aesthetic of the iconic fighting game created by Ed Boon and John Tobias in 1992. It showcases the original dragon emblem, historical background, and external reference links.

## Key Features

* **Responsive Design:** Both the main emblem (`#image`) and text containers (`#tribute-info`) adapt smoothly to desktop and mobile screens.
* **Visual Hierarchy:** High contrast between the dark background (`#141418`), semi-transparent content cards, and red accents to highlight titles and links.
* **User Stories Compliance:** Fulfills all required element IDs and responsive test criteria for the freeCodeCamp *Build a Tribute Page* lab.
