# CSS Nutrition Label

## What I Learned & Practiced

Working on this project helped me master several key CSS and layout concepts:

* **Flexbox Layouts (`display: flex`)**: Understanding how `justify-content: space-between` automatically distributes elements to opposite ends (perfect for aligning nutritional items on the left and percentages on the right).
* **CSS Pseudo-classes (`:not()`)**: Using selectors like `:not(.no-divider)` to conditionally apply styles (like bottom borders) only where needed.
* **Semantic Structure**: Organizing information hierarchically using `header`, `div`, `p`, and `span` tags.
* **Spacing & Indentation**: Utilizing relative units (`rem`, `em`) and margins (`indent`, `double-indent`) to create visual hierarchy for sub-nutrients (like Saturated Fat and Added Sugars).
